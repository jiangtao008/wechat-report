# 微信群周报

`wechat-group-report` 是一个把微信群聊天记录整理为本地 HTML 日报、周报或月报的 Codex skill。它不做流水账式纪要，而是把群内的话题推进、人物角色、情绪起伏和长期兴趣做成一份可直接打开的黑色科技风社群情报报告。

## 输入与输出

**支持输入**

- 直接粘贴的聊天文本
- 本地 `.txt` 聊天导出
- 本地 `.md` 聊天转录
- 本地 `.csv` 聊天导出

**默认输出**

- 完整、可直接在浏览器打开的 `.html` 报告
- 保持黑色科技风模板与单页阅读体验
- 默认保存到本地；除非用户明确要求，否则不只在对话中返回 HTML 源码

## 报告结构

### 1. 区间总览

快速交代本期群聊的基本面：

- 总发言条数与活跃参与人数
- 高频情绪，例如调侃、兴奋、围观、焦虑或捧场
- 每日消息趋势曲线
- 对本期聊天节奏的一句总览判断

### 2. 群聊热点话题

热点数量由真实聊天体量决定，而不是固定配额：

- 轻量聊天：通常 `2–4` 条
- 普通周报：通常 `4–8` 条
- 话题密集、支线丰富的周期：通常 `8–12` 条

高密度话题会按聊天推进顺序展开，交代谁点燃、谁接力、哪里转向、分歧如何出现、最后停在哪。必要时拆成多幕；每幕有具体过程节点，而不是只给结论。

每条话题包含：

- 显眼的话题标题
- 时间线或分幕式过程
- `点睛之笔`：优先引用群友原话
- 默认“腹黑档”AI 锐评
- 主要参与者

### 3. 两性、情感与暧昧专题

当聊天记录中存在足够的多轮互动时，恋爱、相亲、暧昧、情感建议与成人向双关属于优先热点，不会被普通闲聊淹没。

报告会关注谁先抛信号、谁顺势接话、谁在起哄助攻、围观群众如何反应，以及剧情最后落在玩笑、建议、反转还是尴尬收场。文风可以有情趣、暧昧反讽和腹黑旁白，但不会把一句玩笑擅自判定为真实关系或意图。

### 4. 区间活跃之星

活跃榜最多展示 20 人，发言少于 10 条的成员不纳入。每位成员包含：

- 名称与发言次数
- 2–4 句人物侧写
- 1–3 个短标签

人物锐评优先说明群内“剧情职责”：谁是控场手、补刀位、接梗王、抛问机、链接投手，或高频但信息密度堪忧的背景音。它不是批量表扬；点评默认带刺，但必须基于聊天记录。

### 5. 本期话题小森林

关键词云之前会生成一张横向知识森林，呈现群聊背景、持续兴趣和本期具体议题：

- 中央蓝色圆形主节点：报告使用者的核心兴趣与长期关注
- 3–6 个彩色一级主题主卡：例如用车技术、吃喝探索、运动健康、本地生活
- 同色系叶子卡：对应可追溯的具体聊天话题
- 粗色连线：从中心主干向外分叉，形成思维导图式层级

中心兴趣优先依据 `is_self` 或“我”的持续发言推断；证据不足时自动降级为“群聊核心关注”，不把群体偏好硬说成个人画像。所有节点标题不超过 12 个字。

`TOPIC_FOREST_DATA` 的数据结构示例：

```js
{
  center: { title: '智能电动出行', note: '车友群里的长期探索' },
  branches: [
    {
      title: '用车技术',
      icon: '🚗',
      color: '#f27bbc',
      topics: ['家用桩排障', '续航管理']
    }
  ]
}
```

### 6. 关键词云

使用 `canvas + wordcloud2.js` 渲染带权重的二维数组。会过滤低信息量停用词，保留产品名、事件名、名词、动词和反复出现的核心概念。

### 7. 开发者支持区块

报告最后固定显示“这个报告有点意思?”与支持二维码。二维码以内嵌 `data:image/jpeg;base64,...` 形式写入生成结果，因此 HTML 脱离技能目录后仍可独立打开和显示图片。

## 文风与边界

### 默认腹黑档

AI 锐评先给判断、反差或高阶吐槽，再用聊天事实收住。它应像懂群聊的人写的腹黑人物小传或幕后旁白，而不是“促进讨论、贡献价值、活跃气氛”式礼貌复述。

允许调侃：

- 发言频率与信息密度
- 接梗、补刀与带偏方式
- 消费选择和群内剧情职责
- 成人间明确出现的暧昧张力与双关

不会：

- 凭空判断恋爱关系、出轨、性取向或现实动机
- 性化未成年人、年龄不明对象、骚扰或不适内容
- 复述露骨性细节、羞辱性表达或聊天外隐私
- 把玩笑升级为现实人格定性

## 使用方式

在 Codex 中调用 skill，并提供聊天文本或本地导出文件：

```text
使用 $wechat-group-report 分析这份聊天记录，生成群聊周报：/path/to/messages.csv
```

也可以明确指定日报、周报或月报，或要求报告保存到指定本地路径。

## 适用场景

- 微信群日报、周报、月报
- 社群运营复盘
- 热点话题沉淀
- 成员活跃与群聊角色观察
- 兴趣方向与长期讨论脉络整理
